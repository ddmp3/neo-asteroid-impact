# Scripts

Utility scripts for development and deployment.

## Deployment Scripts

- **push-now.sh** - Quick push script (legacy)
- **push-to-github.sh** - GitHub push helper (legacy)

## Usage

```bash
# Make scripts executable
chmod +x scripts/*.sh

# Run a script
./scripts/push-now.sh
```

## Notes

- These scripts are legacy and may need updates for v2.0
- Consider using modern CI/CD pipelines instead
